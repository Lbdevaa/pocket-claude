# pocket-claude

Личный Telegram-бот с Claude. Крутится на домашнем компьютере, отвечает только
владельцу, помнит разговор. Без Docker, без облака, без webhook — long polling
и файл SQLite рядом с кодом.

Две внешние зависимости: `grammy` и `@anthropic-ai/sdk`. Всё остальное —
встроенное в Node 26: база (`node:sqlite`) и чтение `.env` (`--env-file`).

---

## Что понадобится

Node.js 24 или новее (`node -v`) и три вещи, которые нужно получить самому.

### 1. Токен бота

Написать [@BotFather](https://t.me/BotFather) → `/newbot` → придумать имя
и адрес бота. В ответ придёт строка вида `1234567890:AAH...` — это `TG_TOKEN`.

### 2. Ключ Anthropic API

На [console.anthropic.com](https://console.anthropic.com) (это **не** claude.ai,
отдельный сайт для разработчиков):

1. **Plans & Billing** → пополнить баланс, минимум $5
2. **API Keys** → **Create Key** → скопировать `sk-ant-api03-...`

Ключ показывают один раз — закроешь окно, придётся создавать новый.

Подписка Claude Pro/Max для API **не работает**: это разные кошельки. Без
пополненного баланса запросы вернут ошибку даже при активной подписке.

### 3. Свой Telegram user id

Написать [@userinfobot](https://t.me/userinfobot) — он пришлёт число.
Это `ALLOWED_USER_IDS`. Всем остальным бот отвечает отказом.

## Установка

```powershell
npm install
copy .env.example .env
```

Открыть `.env` и вписать три значения из предыдущего раздела. Остальное
можно не трогать — там рабочие значения по умолчанию.

Проверить, что всё сходится:

```powershell
npm run check-net        # доступны ли Telegram и Anthropic
npm run smoke -- привет  # живой ответ модели, без Telegram
```

`check-net` печатает `HTTP 200` и `HTTP 401` — это успех: 401 от Anthropic
означает «сервер на связи, ключа в запросе не было».

Дальше оформить бота в Telegram — описание, подпись в профиле и меню команд:

```powershell
npm run setup-bot
```

Один раз, не при каждом запуске: это настройки на стороне Telegram.
Заменяет ручную возню с `/setdescription` и `/setcommands` у @BotFather.

## Запуск

```powershell
npm start
```

В консоли появится `Бот @имя запущен`. Дальше можно писать ему в Telegram.

Команды бота: `/start` — справка, `/reset` — забыть разговор.

## Настройки в `.env`

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TG_TOKEN` | — | Токен от @BotFather |
| `ANTHROPIC_API_KEY` | — | Ключ с console.anthropic.com |
| `ALLOWED_USER_IDS` | — | Кому можно писать боту, через запятую |
| `MODEL` | `claude-opus-5` | Модель. Дешевле: `claude-sonnet-5`, ещё дешевле `claude-haiku-4-5` |
| `MAX_TOKENS` | `16000` | Потолок длины одного ответа |
| `HISTORY_LIMIT` | `30` | Сколько последних сообщений помним |
| `PARSE_MODE` | `Markdown` | Разметка: `Markdown`, `MarkdownV2`, `HTML`, `none` |
| `SYSTEM_PROMPT` | задан | Манера ответа. Одной строкой — переносы `.env` не понимает |

Менять можно на ходу, нужен только перезапуск бота.

### Сколько это стоит

Одно сообщение с историей в 30 реплик — примерно 3000 токенов на вход
и 500 на выход:

| Модель | За сообщение | При 20 сообщениях в день |
|---|---|---|
| `claude-opus-5` | ~$0.03 | ~$17/мес |
| `claude-sonnet-5` | ~$0.011 | ~$6,6/мес |
| `claude-haiku-4-5` | ~$0.0055 | ~$3,3/мес |

Повторяющаяся часть истории кэшируется, так что на практике выходит дешевле.
Тратится по факту, остаток баланса не сгорает.

## Автозапуск при включении компьютера

`pm2` тут не подходит: его команда `pm2 startup` на Windows не поддерживается.
Используем Планировщик заданий — он у Windows свой и работает надёжно.

Запускать нужно `start.bat`, а не `npm start` напрямую: обёртка ждёт появления
сети (после перезагрузки VPN поднимается не мгновенно) и перезапускает бота,
если тот всё же упал.

1. `Win+R` → `taskschd.msc`
2. Справа — **«Создать задачу…»**, именно её, а не «Создать простую задачу»
3. **Общие**: имя `Pocket Claude`, переключатель **«Выполнять только для
   вошедших пользователей»**
4. **Триггеры** → «Создать» → **«При входе в систему»**
5. **Действия** → «Создать» → «Запуск программы»:
   - Программа: полный путь к `start.bat`
   - Рабочая папка: папка проекта
6. **Условия**: снять «Запускать только при питании от электросети», иначе
   на ноутбуке бот не поднимется от батареи
7. **Параметры**: снять **«Останавливать задачу, выполняемую дольше 3 дней»** —
   иначе Планировщик молча убьёт бота через три дня работы

Проверять нужно настоящей перезагрузкой: на «работает же сейчас» полагаться нельзя.

Про триггер отдельно. «При входе в систему» выбран не случайно: VPN у тебя —
обычное приложение, которое стартует вместе с твоим сеансом. Задача, запущенная
«вне зависимости от регистрации пользователя», уйдёт в отдельный сеанс, где
этого VPN нет, и будет ждать сеть до самого твоего входа. Толку от такого
раннего старта никакого, а пароль учётной записи Планировщику пришлось бы
сохранить.

Окно консоли при запуске будет видно — так проще заметить, что бот жив.
Логи пишутся в `logs/bot.log`.

## Если что-то не работает

**Бот молчит.** `npm run check-net` — включён ли VPN. Оба API должны отвечать.

**`Ключ Anthropic не принят`.** Опечатка в `ANTHROPIC_API_KEY` либо ключ отозван.

**`Запрос отклонён: ... credit balance`.** Кончился баланс на
console.anthropic.com. Подписка Claude.ai его не пополняет.

**Ошибка про настройки при старте.** Бот перечисляет все проблемы `.env` разом
и выходит. Сверяйся с `.env.example`.

**Ответы приходят со звёздочками вместо оформления.** Telegram не смог разобрать
разметку и получил текст как есть — это штатный запасной путь, ничего не потеряно.
Если раздражает, поставь `PARSE_MODE=none`.

**Бот не поднялся после перезагрузки.** Смотри `logs/bot.log`: там видно,
дождался ли `start.bat` сети и запускался ли `npm start` вообще.

## Что внутри

```
src/index.js      точка входа: whitelist, команды, «печатает», обработка ошибок
src/config.js     чтение и валидация .env, единственное место с process.env
src/claude.js     запрос к Anthropic, разбор ответа, ошибки человеческим языком
src/history.js    история диалогов в node:sqlite, последние N сообщений на чат
src/telegram.js   разбиение ответа >4096 символов, запасной путь без разметки

scripts/check-net.js    доступны ли оба API
scripts/smoke-claude.js ответ модели без участия Telegram
scripts/setup-bot.js    описание бота и меню команд
```

Замысел и порядок работ — в [plan.md](plan.md), требования — в [TASK.md](TASK.md).

## Приватность

`data/history.db` — это архив твоей переписки в открытом виде, а `.env` —
ключи. Оба лежат в `.gitignore` и не должны попадать в git: из истории
репозитория их потом не убрать. Ключ отзывается за минуту, переписка — нет.

В логи пишется только длина сообщения и id чата, но не текст.
